# 候选质量验收与本机试用（2026-11-19）

本次实现覆盖词频尺度校准、离线词语／字符语言模型、整句搜索、末尾音节补全、光标前文排序和个人学习的边界。目标是日常聊天与办公输入，安装使用本机完整词库与明确授权的 Tatoeba 模型。完整第三方词库与模型不属于公开 MIT 演示数据，未进行公开发行。

## 质量结果与评测范围

固定的扩展句集按模板划分为开发集 300 句和验收集 300 句，各覆盖全拼、简拼、混合拼写，共各 900 例。评测使用空个人词库、默认设置，无应用前文。验收集首选由 157/900 提升至 336/900，错误数由 743 降至 564，相对减少 **24.09%**，超过预定 20% 门槛。

- 全拼：首选 137 → 228/300，前五 213 → 268/300。
- 简拼：首选 10 → 39/300，前五 13 → 55/300。
- 混合：首选 10 → 69/300，前五 13 → 140/300。
- 开发集：首选 291 → 402/900，错误相对减少 **18.23%**；三个类别的前五均改善。开发集本身未达到 20%。
- 原有常用词 200 例保持 200/200；原有句子 75 例保持 74/75。
- 新增词频抽样 300 词：首选保持 289/300，前五保持 299/300。

这些是原创模板构造的合成回归样本，词样本的读音来自词库；不是自然输入准确率。尤其简拼存在很高歧义，首选仍有明显提升空间。首轮冻结验收结果为 16.55% 错误减少；随后修复通用长句被错误当作单个动词头、以及搜索状态合并丢失不同前缀的问题，并重跑同一验收集。训练语料、答案和模型权重没有据此改变，但最终结果不能当作一次性盲测的独立泛化估计。

基线保留于 `build/quality-2026-11-18/baseline/`，包含评测可执行文件、原始词库、候选轨迹与 SHA-256 清单。冻结时工作区已有先前修改，不能仅用 Git HEAD 重建；保留产物的哈希才是本次比较依据。

## 模型、排序与隐私

模型使用 2026-11-14 详细普通话快照，经繁简转换、中文分句和词典分词后得到 97,929 条外部子句，加上 2,000 条原创办公／对话训练句。原始或近似命中评测集的 86 条子句被排除。模型包含 199,999 条词语／字符统计，约 7 MiB；复现训练得到字节一致的模型正文。原始下载、正文和署名的校验值保存在构建证据与安装元数据中。

Tatoeba 语料使用 CC BY 2.0 FR；来源、许可、句子 ID 和提供的作者名保存在安装目录 `share/licenses/waypinyin/` 的 `Tatoeba-model-NOTICE.txt`、`language-model.json`、`language-model-attribution.tsv`。空缺作者名保持原始空缺，不编造署名。所有处理在本机完成，没有上传输入内容，也没有把个人学习日志纳入训练。

`lexicon.lm` 是可选旁文件，版本、词库指纹和正文校验不匹配时诊断并回退基础引擎。构建只有显式指定 `WAYPINYIN_MODEL_BODY` 才启用模型，不会隐式下载或拿微型测试模型充当正式模型。词频按来源共同词校准，同时保留一半原始先验与常用词锚点。

搜索结合词语一至三元统计、字符搭配与词频；保留不同分词历史和有限数量的竞争前缀。基础路径失败时可尝试整句至多一次编辑修复。单音节字符和短码保留基础路径；末尾未完成音节可按语境补全，提交读音与显式分隔符由回归测试保护。

设置中的“上下文增强”和“使用光标前文本”（`contextual`、`surrounding`）默认开启，旧配置兼容。IBus 周边文本按 Unicode 字符偏移截取光标前最多 64 字，只在内存中使用，不写入日志、不训练、不送入预加载。选择区域、失焦、重置和私密输入会清除或拒绝前文。应用不提供前文时使用本输入法当前句已确认文本。外部光标移动不会被误学成个人词语关联；关闭上下文也保留原有个人学习功能。上下文单词加权最多两倍，个人学习原有至多九倍及衰减、删除行为保留。

实际隔离 IBus 测试验证了“我想去”使 `beijing` 优先“北京”，前文改为“照片的”后立即重绘并优先“背景”，随后空格提交“背景”。还覆盖 Unicode 光标、私密输入、发现组件和正常提交。

## 性能与构建验收

性能与安装的最终机器记录见 [JSON 证据](benchmarks/quality-2026-11-19.json)。核心与隔离 IBus 路由使用串行七轮，报告每轮分位数的中位数；基线与新版分别使用各自配套词库、空配置及空个人学习目录。周边文本分别测试 0、16、64 字。测量包含引擎／总线路由，不代表物理键盘至屏幕呈现的端到端延迟。

七轮核心按键 P95 中位数：普通句子 3.928 ms，短码 0.261 ms（基线 0.256 ms，增加约 1.8%）；16/64 字前文的句子分别为 8.750/8.794 ms。普通句子按键 P95、短码 P95 回退幅度、16/64 字前文的句子 P95、确定性轨迹和内存上限均按计划验收。内存同时保留原安装引擎的同负载隔离快照；采用整个引擎高水位不超过 256 MiB 的检查，比“新增内存不超过 256 MiB”更严格。实测隔离引擎高水位最高 164.58 MiB，相对原安装版的中位增量约 17.93 MiB。100 次引擎创建／销毁验证总线对象释放。

普通句子的 P95 门槛不是逐键最大耗时保证。编辑修复存在数十毫秒长尾；8–256 字母的重复高歧义／无效输入压力测试也存在约 50–126 ms 的单键长尾。压力样本与句集回归同时运行，仅作鲁棒性记录，未用于串行性能对照。压力样本完整运行并受分段搜索预算约束，详细原始记录保存在构建目录；这些异常输入不包含在普通句子小于 10 ms 的结论中。

最终 `cargo fmt`、全部目标 Clippy（警告视为错误）、release 测试通过：104 项库测试、4 项 CLI 测试；另 1 项需要外部原生词库样本的测试未运行。三个 Python 安装／回滚测试通过（包括 IBus 延迟启动恢复）。演示词库先前单独通过 47 项测试。来源清单通过校验；历史完整词库仍有 7 项再分发来源问题，本次本机试用没有改变公开发布状态。

## 复现与回滚

先按照 README 的显式语料训练方式生成正文与来源文件，再使用同一安装前缀构建：

```sh
export WAYPINYIN_SOURCE_DATA="$PWD/data"
export WAYPINYIN_MODEL_BODY="$PWD/build/quality-2026-11-18/tatoeba-model.txt"
export WAYPINYIN_DATADIR="$HOME/.local/share/waypinyin"
make build PREFIX="$HOME/.local" CARGO_BUILD_FLAGS='--locked --offline'
cargo build --offline --release --examples
python3 scripts/evaluate_quality.py --image build/lexicon.bin --split test \
  --baseline build/quality-2026-11-18/baseline/expanded.tsv \
  --output build/quality-2026-11-18/holdout-final.json
python3 scripts/quality_acceptance.py \
  --baseline build/quality-2026-11-18/baseline --image build/lexicon.bin \
  --engine build/waypinyin --probes target/release/examples \
  --output build/quality-2026-11-18/deployed-acceptance --runs 7
```

本机安装与回滚位置由最终机器记录中的 `installation` 字段给出。安装前对暂存文件、桌面注册和模型加载做验证；安装采用原子替换并保存旧文件和个人日志快照，保留当前学习日志、导入词库与设置。只重新加载本前缀的输入法进程，不重启整个 IBus。回滚工具核对文件哈希，恢复旧安装文件，同时保留安装后产生的个人学习。

实际安装前缀为 `/home/emt/.local`，已核验运行中的新版可执行文件哈希、词库映射 inode、模型与署名元数据，并再次通过安装版隔离 IBus 测试。9 个既有导入／配置文件的哈希保持不变。首次切换的 IBus 命令返回失败，但组件随后完成异步启动并选中 Waypinyin；现已在重载工具中加入有界重试和实际选中状态检查，避免把延迟启动误报为失败。

旧版本及个人日志快照保存在 `/home/emt/.local/share/waypinyin/backups/quality-2026-11-19-8ebf376586b1`。如需回滚：

```sh
backup="$HOME/.local/share/waypinyin/backups/quality-2026-11-19-8ebf376586b1"
python3 "$backup/trial_install.py" --rollback "$backup"
```

回滚会重新选择原安装引擎；个人日志快照仅供恢复参考，不自动覆盖当前学习日志。当前桌面真实键盘输入与视觉体验尚需用户日常试用，自动验收未冒充物理桌面端到端验证。
